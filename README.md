- **[`sortir-yolo/`](sortir-yolo/)** : Direktori utama program deteksi, kalibrasi robot, auto-capture dataset, dan pengujian.
  - [**`sortir-yolo/README.md`**](sortir-yolo/README.md) : Panduan operasional & *cheat sheet* perintah cepat.
  - [**`sortir-yolo/DOKUM/DOKUMENTASI.md`**](sortir-yolo/DOKUM/DOKUMENTASI.md) : *Master Technical Knowledge Base*, arsitektur sistem, Colab, dan resume training.
  - [**`sortir-yolo/DOKUM/PANDUAN_TIM_ROBOTIK.md`**](sortir-yolo/DOKUM/PANDUAN_TIM_ROBOTIK.md) : Panduan integrasi koordinat robotik Windows, G-Code, dan Stop-and-Go.
  - [**`sortir-yolo/DOKUM/WORK_DOKUMENTATION.md`**](sortir-yolo/DOKUM/WORK_DOKUMENTATION.md) : Log berkala laporan pengembangan mingguan & harian.
