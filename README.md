# opencv

Sistem Visi Komputer Sortir Otomatis Berbasis YOLOv8 + OpenCV dan Integrasi Robot Lengan (RNV3).

## 📁 Struktur Repositori

- **[`sortir-yolo/`](sortir-yolo/)** : Direktori utama program deteksi, kalibrasi robot, auto-capture dataset, dan pengujian.
  - [**`sortir-yolo/README.md`**](sortir-yolo/README.md) : Panduan operasional & *cheat sheet* perintah cepat.
  - [**`sortir-yolo/DOKUMENTASI.md`**](sortir-yolo/DOKUMENTASI.md) : *Knowledge base* teknis lengkap, arsitektur sistem, dan catatan masalah/solusi.
  - [**`sortir-yolo/PANDUAN_TIM_ROBOTIK.md`**](sortir-yolo/PANDUAN_TIM_ROBOTIK.md) : Panduan koordinat milimeter dan kalibrasi untuk tim robotik.
- **[`arsip_luar/`](arsip_luar/)** : Arsip dokumen, skrip non-aktif, dan screenshot versi terdahulu.
